# HTML Tags Cheatsheet

## Document Structure
| Tag | Kaam |
|-----|------|
| `<!DOCTYPE html>` | HTML5 document declare |
| `<html>` | Root element |
| `<head>` | Meta information |
| `<body>` | Visible content |

## Text Tags
| Tag | Kaam |
|-----|------|
| `<h1>` to `<h6>` | Headings |
| `<p>` | Paragraph |
| `<strong>` | Bold (important) |
| `<em>` | Italic (emphasis) |
| `<br>` | Line break |

## Semantic Tags
| Tag | Kaam |
|-----|------|
| `<header>` | Top section |
| `<nav>` | Navigation |
| `<main>` | Main content |
| `<section>` | Thematic block |
| `<article>` | Independent content |
| `<aside>` | Side info |
| `<footer>` | Bottom section |

## List Tags
| Tag | Kaam |
|-----|------|
| `<ul>` | Unordered list |
| `<ol>` | Ordered list |
| `<li>` | List item |

## Link & Media
| Tag | Kaam |
|-----|------|
| `<a href="">` | Link |
| `<img src="" alt="">` | Image |

## Meta Tags
| Tag | Kaam |
|-----|------|
| `<meta charset="UTF-8">` | Character encoding |
| `<meta name="viewport" content="...">` | Mobile viewport |
| `<title>` | Page title |
| `<link rel="stylesheet" href="...">` | CSS file link |
| `<script src="..."></script>` | JS file link |
